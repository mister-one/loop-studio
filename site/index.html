How it works

Publish an event

Emit a named event with a JSON payload from the workspace or HTTP API. Set an interval when you want Loop to emit it automatically.

Connect a model

Pick a topic and give your loop an instruction. Use the demo processor or point Loop at an OpenAI-compatible endpoint such as a local Ollama server.

Inspect the result

Review inputs, outputs, and failures in the console. Publish the model response as a new event when another loop needs to pick it up.

Start Loop Studio

Get the source, open its folder, and run Loop with Node.js 22 or later. Open the local URL printed in your terminal.

npm start
